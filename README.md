# GEO-SEO-WORK

This is the shared record for the CROOKSLDN GEO and SEO programme (crooksldn.com). This repository is public.

## How it works

- Each Cowork workstream works only on its own branch, `cowork/<workstream-slug>`, cut from `main`.
- Each workstream keeps `workstreams/<slug>/STATUS.md`, `FINDINGS.md`, `CHANGES.md` and `NEXT.md` on that branch. Supporting files go in `workstreams/<slug>/artifacts/`.
- Nobody commits to `main` or merges their own branch. The programme orchestrator decides what gets merged.
- The `cowork/programme-records` workstream keeps the change log, the master queue and the status report. It merges each workstream's `CHANGES.md` into the change log. Other workstreams don't edit those files.

## Evidence rule

A deploy is not proof. A ranking, traffic or GEO improvement is recorded only against a captured measurement. GEO 43/50/54 and SEO health 70/74 have no recorded method, so they are kept only as labelled historical figures and are never cited as evidence.
