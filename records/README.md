# Programme records

These three files are the programme's record. Only `cowork/programme-records` edits them; other workstreams log their own changes in `workstreams/<slug>/CHANGES.md`.

| File | What it is |
|---|---|
| `change-log.md` | Every change made, and whether it is live, with its metric, baseline and review dates |
| `master-queue.md` | Every queued action, with its status |
| `status-report-2026-10-16.md` | Status for George, with dated Update sections at the top |

**Source.** The files were first committed exactly as imported, from `cowork/project-files-import` commit `1c98fb3` (the Project's `seo/` folder, sanitised under owner decision #16). Every edit after that is its own commit on this branch, so `git log -p records/` shows what changed and when.

**Public repo.** No revenue, exact order counts, private addresses, age or IP details are kept here (decision #16).

**Back to the Project.** The main chat copies these files back to the Project folder, or merges them, when it chooses (George, 18 Oct, answer 9).
